# Nag & Associates – Website

Static website for **Nag & Associates** (Survey Consultancy · Digital Survey & Printing Solution, Raniganj) and its sister concern **Aadrita Buildcon LLP** (commercial building construction).

## Structure
- `index.html` – single-page site (Home, About, Survey Services, Plans & Approvals, Printing, Aadrita Buildcon LLP, Contact)
- `assets/css/style.css` – styles (responsive)
- `assets/js/main.js` – mobile menu, scroll effects, enquiry form (opens WhatsApp or email)

## Run / Host
No build step. Open `index.html` in a browser, or upload the whole folder to any static host (Hostinger, GitHub Pages, Netlify, etc.).
